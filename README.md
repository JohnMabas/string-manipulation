# string-manipulation

A simple JavaScript project with three string manipulation programs.

Tasks
1. Initials Generator
Asks for a full name and generates initials from the first two names.

Example: Andrew Solex → A.S
2. Letter Position Finder
Asks for a sentence and a letter, then finds the position of the letter in the sentence.

Returns -1 if the letter is not found
3. Username Generator
Creates a username from first and last name with the total character count appended.

Example: andrew solex → andrewsolex_11
How to Use
Open index.html in a browser or run script.js in Node.js. Follow the prompts to use each program.

Files
index.html - HTML file to run the scripts in a browser
script.js - JavaScript implementation of all three tasks
